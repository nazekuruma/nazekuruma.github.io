プライバシーポリシー

「ナゼクルマ投稿PC」（以下「本ツール」）は、YouTubeチャンネル「ナゼクルマ」の運営者が、自分のチャンネルに動画を投稿するためだけに使うツールです。本ツールが扱うデータと、その扱い方を次のとおり定めます。

This page describes how "NazeKuruma Upload PC", a private tool used only by the operator of the YouTube channel "NazeKuruma", accesses and handles Google user data.

最終更新日：2026年11月26日

1. 利用者

本ツールを使うのは、ナゼクルマの運営者本人だけです。一般の利用者がログインして使うサービスではなく、ほかの人のGoogleアカウントのデータは扱いません。

2. YouTube API サービスの利用

本ツールは YouTube API サービス（YouTube Data API）を使っています。本ツールを使うことは、YouTube の利用規約に同意することになります。Google によるデータの扱いは、Google のプライバシーポリシーをご覧ください。

3. 使う権限と取得するデータ

運営者が自分のGoogleアカウントで許可したときだけ、次の2つの権限を使います。

  • youtube.upload：運営者が作って確認した動画とサムネイルを、ナゼクルマのチャンネルにアップロードするため
  • youtube.readonly：投稿先がナゼクルマのチャンネルであることを確かめるために、チャンネルの識別子と名前を読み取るため。アップロードした動画の公開設定と処理の状態を確かめるため

Googleアカウントのパスワード、メールアドレス、ほかのチャンネルや視聴者個人を特定する情報は取得しません。

4. 使い道

取得したデータは、運営者が自分の動画を投稿し、投稿できたかを確かめるためだけに使います。運営者が自分の制作のために使うツール（AIのアシスタントを含む）で処理することがあります。広告への利用、第三者への販売・提供はしません。

本ツールがGoogle APIから受け取ったデータの使用と移転は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. 保存と削除

  • Googleの認証情報は、運営者のPCの中の、運営者のアカウントだけが読める場所に暗号化して保存します。外部のサーバーには置きません。
  • 保存するのは、チャンネルの識別子と名前、投稿した動画の識別子・URL・公開設定です。運営者の制作の記録として残ります。

6. 許可の取り消し

本ツールへの許可は、Googleアカウントの「サードパーティとの接続」からいつでも取り消せます。取り消すと、本ツールは動画を投稿できなくなります。

7. 変更

このポリシーを変えるときは、このページを更新し、最終更新日を書き換えます。

8. お問い合わせ

YouTubeチャンネル「ナゼクルマ」までお願いします。
