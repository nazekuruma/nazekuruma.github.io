ナゼクルマ投稿PC

YouTubeチャンネル「ナゼクルマ」（車の「なぜ」に公的データで答える動画）の運営者が、自分のチャンネルに動画を投稿するために使っている、運営者専用のツールです。

NazeKuruma Upload PC is a private tool used only by the operator of the YouTube channel "NazeKuruma" to upload the channel's own videos.

このツールがすること

  • 運営者が自分のGoogleアカウントで許可したときだけ、ナゼクルマのチャンネルに、運営者が作って確認した動画とサムネイルをアップロードします（YouTube Data API の youtube.upload の権限）。
  • 投稿先がナゼクルマのチャンネルであることを確かめるために、チャンネルの識別子と名前を読み取ります（youtube.readonly の権限）。
  • 動画の削除、コメントの書き込み、チャンネルの設定の変更はしません。
  • ほかの人のアカウントやチャンネルのデータは扱いません。一般の利用者向けのサービスではありません。
